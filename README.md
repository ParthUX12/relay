# Relay — AI Command Center
 
Relay is a UX and product design case study for an AI orchestration platform. Instead of juggling separate AI tools, subscriptions, and apps, Relay lets a person describe what they want to get done — and it figures out which AI tools and connected apps should handle each step, shows the plan before anything runs, and only acts with the permission you've given it.
 
Think of it as a coordination layer that sits on top of the AI tools you already pay for — Relay doesn't replace them, it decides which one should handle each part of a task, and then gets the work done across all of them on your behalf.
 
## What's inside
 
This repository holds the complete design work behind the project, including:
 
- Product strategy and positioning
- User research approach and competitive analysis
- Personas and the core user problem the project addresses
- End-to-end user flows, from connecting a tool to approving an AI action
- Screen designs covering the main product experience
- Supporting documentation explaining key design decisions
## The problem
 
AI power users today run several AI subscriptions and tools at once — one for research, another for writing, another for design — with no single place to decide which tool actually fits a given task. On top of that, there's no easy way to track what all these subscriptions are costing, and no consistent way to trust an AI agent enough to let it act inside other apps on your behalf. Relay is the coordination layer designed to solve all three of these problems at once, rather than adding yet another standalone AI tool to the pile.
 
## Who it's for
 
Relay is designed primarily for people who already use multiple AI tools regularly — researchers, designers, developers, and knowledge workers who find themselves switching between apps and re-explaining context every time they move from one tool to the next.
 
## Status
 
This is a self-directed portfolio project — a design exploration built to demonstrate product and UX thinking, not a shipped or commercially available product.
